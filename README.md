# نقاء AI — Naqaa AI (Android prototype)

نسخة أولية لتطبيق أندرويد لتحسين الصور التي تحتوي على وجوه وأشخاص.

## الموجود في النسخة 0.1.0
- واجهة عربية RTL.
- اختيار صورة عبر Android Photo Picker دون طلب صلاحية قراءة مكتبة الصور كاملة.
- معاينة الصورة.
- حفظ نسخة JPEG محسّنة إلى مجلد Pictures/NaqaaAI في المعرض.
- تحسين محلي تجريبي بمرشح حدة بسيط قابل لضبط القوة.
- لا يتم رفع الصور إلى أي خادم في هذه النسخة.

## حدود مهمة
مرشح الحدة الحالي ليس نموذج ذكاء اصطناعي لإصلاح الوجوه، ولا يزيل الضبابية الشديدة أو يستعيد تفاصيل مفقودة. لا تُعرض هذه النسخة على أنها معالجة إنتاجية. الخطوة التالية هي دمج نموذج محلي فعلي لتقليل الضوضاء/تحسين الصورة، ثم واجهة API سحابية آمنة مع موافقة صريحة قبل الرفع.

## البناء
1. افتح المجلد في Android Studio حديث.
2. استخدم JDK 17.
3. نفّذ Gradle Sync.
4. شغّل التطبيق على جهاز أو محاكي Android 8.0+.

## البنية التالية المقترحة
- `ImagePicker`: اختيار الصورة وإدارة النسخة الأصلية.
- `LocalEnhancementEngine`: استبدال المرشح التجريبي بنموذج TFLite/ONNX مناسب.
- `CloudRestorationClient`: واجهة منفصلة للخادم، لا تضع مفاتيح API السرية داخل التطبيق.
- `ResultRepository`: حفظ نسخة جديدة إلى MediaStore بعد موافقة المستخدم.
- خادم وسيط: مصادقة، حدود حجم، حذف تلقائي للصور، نقل HTTPS، وموافقة واضحة قبل الرفع.
- اختبارات جودة على صور متنوعة مع تجنب تغيير الهوية أو توليد تفاصيل وجه غير موثوقة.

## الحالة
واجهة اختيار الصور والتحسين المحلي التجريبي موجودة. حفظ الصورة إلى المعرض موجود. المعالجة السحابية ونموذج الوجه الحقيقي لم يُنفّذا بعد.
